Cloud usage bill

A cloud usage export, one row per instance family and region. The platform reads the usage hours, separates GPU from general-purpose instances, and calculates what it can.

Demo. This shows how the platform reads a cloud usage export. It is not a connection to any provider.

Sample export: cloud usage (CSV)

instance_type,region,usage_hours,cost
gpu-a100-x4,ap-south-1,9000,2700000
gpu-a100-x4,ap-south-1,4000,1200000
m6i.large,ap-south-1,36000,450000

How the platform reads it

STEP 1

Read the export

Each row is a billed usage line, with its region and hours.

STEP 2

Map the columns

Instance type, region, usage hours and cost are matched by name.

STEP 3

Classify instances

GPU families use the GPU factor. General-purpose families have no factor yet, so they are flagged.

STEP 4

Calculate Scope 3.1

GPU hours × 0.4 kg CO₂e per hour. Illustrative until a verified source is added.
